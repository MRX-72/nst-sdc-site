# Process

## Selected theme

College Dev Club

## Tech stack

HTML, Tailwind CSS

## Thought process and work

I chose College Dev Club as my theme because it's something I'd like to contribute to, by creating or improving its site.

### Research

The logical first step was to check the official existing site and GitHub repo of NST SDC. I asked a member of NST SDC, Arpit Singh, who showed me the club's original GitHub repo. I used it as a reference, read through it, and noted down:

- The flagship hackathon
- The members and their roles
- Their projects
- Their initiatives for:
  - Hacktoberfest
  - GSoC
  - Showcasing student projects
  - Organizing coding competitions
- Their mission

### Why this challenge

I'm more into low-level networking, cyber security and core programming, so a good-looking frontend is a challenge for me; it's not my forte. That was my main reason for joining the hackathon: to challenge myself in UI/UX.

### Preparation

I was fairly fluent with vanilla CSS and Tailwind a year ago, so I brushed up on them before the hackathon, especially the parts that weren't in my active memory.

I also watched YouTube videos on UI design and color theory, and honestly found them pretty interesting.

### Design and build

I was already familiar with tools like Google Stitch and Claude Code. After brainstorming on my own and sketching out a detailed picture of the UI in my head, I used Google Stitch to see how it would look. I went back and forth with it and settled on a final design.

I wrote the raw backbone of the site myself. There were a few features I couldn't implement on my own, like the background of the About section, so I used Claude Code for those. I also used it to simplify my code and to create branches for testing slight font changes and different color palettes.

Once that was done, I adjusted font sizes where needed, ran final experiments with the gradients, and made sure the site looks minimal, informative and neat.

### Deployment

I pushed the final branch to GitHub and deployed the site to Firebase. I picked Firebase because its shareable link looks clearer and more professional than Vercel's:

- Firebase: `<name>.web.app`
- Vercel: `<name>.vercel.app`
